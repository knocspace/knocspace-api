## 목표

프론트의 자동 저장(F4)이 이 서버로 붙어도 **글자가 사라지지 않게** 합니다.

F4의 자동 저장은 타이핑이 멈추고 800ms, 계속 치면 5초마다 저장을 보냅니다. 한 사용자가 문서 하나를 쓰는 동안 분당 수십 번 요청이 옵니다. 그걸 견디는 게 이번 주 일입니다.

## 만드는 것

- `version` 기반 충돌 감지와 `409` 응답
- 본문 크기 제한과 검증
- 연속 저장 부하 대응
- 부하 테스트 스크립트

---

## 할 일

### 1. 낙관적 잠금

- [ ] `If-Match` 헤더로 `baseVersion`을 받습니다 ([계약 2번](api-contract.md#2-baseversion을-어디로-보낼지))
- [ ] 조건을 `UPDATE` 문 안에 넣습니다

  ```sql
  UPDATE "Page" SET ..., version = version + 1
  WHERE id = $1 AND version = $2
  ```

  **`SELECT`로 버전을 확인한 뒤 `UPDATE`하지 않습니다.** 두 요청이 같은 버전을 읽고 둘 다 성공합니다

- [ ] 0행이 바뀌면 `409 version_conflict`
- [ ] **409 응답 본문에 서버의 현재 `Page`를 담습니다.** 프론트 충돌 다이얼로그의 "서버 것 불러오기"가 요청을 한 번 더 안 하게
- [ ] `If-Match`가 없으면 버전 검사를 건너뜁니다 (제목만 고치는 경우)

### 2. 본문 저장

- [ ] `content`는 `BlockDoc` 모양(`format` `schemaVersion` `blocks`)만 확인하고 **`blocks` 안은 열어보지 않습니다**
- [ ] 1MB를 넘으면 `413 too_large`. Fastify `bodyLimit`도 같이 올려둡니다
- [ ] `schemaVersion`이 모르는 값이어도 거절하지 않고 저장합니다. 프론트가 먼저 배포될 수 있습니다
- [ ] `updatedBy`를 채웁니다 (B4 전까지는 `local-user`)

### 3. 연속 저장 견디기

- [ ] 같은 페이지에 저장이 몰려도 잠그지 않습니다. 버전 검사로 충분합니다
- [ ] `content`가 안 바뀌었으면 `version`을 올리지 않습니다 — 프론트의 강제 5초 저장이 헛 버전을 만들지 않게
- [ ] `PATCH` 응답에서 `content`를 빼는 것을 검토합니다. 1MB를 받아서 1MB를 돌려주면 왕복이 두 배가 됩니다
  - **계약 변경이므로 프론트와 합의합니다.** 합의 못 하면 그대로 돌려줍니다
- [ ] Postgres 커넥션 풀 크기를 정합니다 (기본값 그대로 두지 않습니다)

### 4. 부하 확인

- [ ] `scripts/load-save.ts` — 800ms 간격으로 100KB 본문을 10분간 저장
- [ ] 확인할 것
  - 실패 0
  - p95 지연이 시간이 갈수록 증가하지 않음
  - 커넥션 풀이 고갈되지 않음
  - 테이블 크기가 저장 횟수에 비례해 늘지 않음 (Jsonb는 덮어쓰기입니다)

### 5. 테스트

- [ ] `baseVersion`이 맞으면 저장되고 `version`이 1 오른다
- [ ] 틀리면 `409`가 오고 **데이터가 안 바뀐다**
- [ ] 409 본문에 서버의 현재 `Page`가 들어 있다
- [ ] 같은 `baseVersion`으로 동시에 두 번 보내면 **정확히 하나만** 성공한다 (`Promise.all`로 실제 동시 요청)
- [ ] 1MB 초과는 `413`
- [ ] 같은 `content`를 두 번 저장하면 `version`이 한 번만 오른다

네 번째가 이번 스프린트의 핵심 테스트입니다. 순차로 보내면 잘못 구현해도 통과합니다.

---

## 완료 조건

- [ ] 두 탭에서 같은 페이지를 고치면 나중 저장이 `409`를 받고, 프론트가 선택지를 띄운다
- [ ] 동시 요청 테스트에서 하나만 성공한다
- [ ] `PATCH` p95 150ms 이내 (100KB 본문)
- [ ] 10분 부하 테스트에서 실패 0, 지연 증가 없음
- [ ] 서버 코드에 `content.blocks`를 들여다보는 곳 0개
- [ ] 로그에 본문 내용이 남지 않는다 (크기만)

[공통 완료 조건](conventions.md)도 함께 확인합니다.

---

## 끝나면 할 수 있는 것

프론트 F4의 자동 저장이 localStorage 대신 이 서버에 씁니다.
**혼자 쓰는 노션이 실서버 위에서 돕니다.** 아직 로그인은 없습니다.
